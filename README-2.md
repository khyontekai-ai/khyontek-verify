# Collaborator Logos

Place collaborator institution logo files here before issuing collaborative certificates.

## Naming convention
- iitg.png        → IIT Guwahati
- gmch.png        → Gauhati Medical College and Hospital
- aiims.png       → AIIMS Guwahati
- nlu.png         → North Lakhimpur University
- rmrc.png        → RMRC Dibrugarh
- bbci.png        → B. Borooah Cancer Institute

## Requirements
- Format: PNG preferred (transparent or white background)
- Height: Any — script auto-scales to 150px maintaining aspect ratio

## How to add
1. Get logo PNG from the institution
2. Rename using convention above
3. Copy into this folder
4. Push: git add scripts/fonts/collab-logos/ && git commit -m "Add logo" && git push

## NJK Signature
Place njk_signature.png in scripts/fonts/ (not here) to enable the NJK signature toggle in the admin panel.
